One funny single-line excuse a developer gives when code breaks in production, under 200 characters.

## Entry

> The bug only happens in production because that's the only place anyone actually uses the feature.

## How it works

`main.py` writes the entry line to `/output/entry.txt` (or `$ENTRY_OUT` when set), after checking it locally against the competition gate: one line, 1–200 characters, UTF-8.

```sh
python3 main.py
cat /output/entry.txt
```
